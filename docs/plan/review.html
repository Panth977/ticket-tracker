Review

This page records a pass over the whole plan. For each feature I checked three things: where it is stored, which command changes it, and which screen shows it and how you get there. Each gap below has a recommendation. Fixed means the recommendation is already in the App and Platform tabs. Decided means you made a call that removed the gap. Open means it still needs a choice or is deliberately deferred.

Navigation

Rule: everything is reachable from the sidebar, at most two clicks deep. A toolbar may repeat a shortcut, but it is never the only way to reach a screen.

Phase 2: agents

The same three questions, asked of the agents spec.

GapRecommendationStatus
An agent needs an identity that fits every field a person already sits inA principal id: a uid or ag_ + 16. The prefix tells them apart, so no field grew a second shape and no phase-1 document migrates. members/{id}.kind says which for display.decided
Agents in readerUids would reach the security rules, which only know Firebase usersAgents never sign in; they act only through a token, and the door checks access. readerUids / editorUids stay people-only.decided
Where an agent profile lives and who can read its system promptagents/{agentId}, readable by its owner only. Boards see the copy in members/; the prompt goes only to the agent's own tokens (GET /v1/me, whoami).fixed
Adding an agent by invite has nobody to acceptboardAgentSet: an admin who owns the agent adds it directly, never as admin. Any admin may re-role or remove it.fixed
Agents cannot receive push, email or WhatsAppnotify writes agentInbox instead, not collapsed, never for the agent's own actions. Read through a cursor, an SSE stream or MCP, and acked with agentInboxAck.fixed
A token spanning several boards is too much to hand an orchestratorapiKeys v2: one board each, actsAs you or an agent, fine-grained scopes with presets. Phase-1 keys read as revoked.decided
A token outliving its agent or its board membershipagentArchive, boardAgentSet role:null and leaving a board revoke the tokens, with a reason the Tokens list shows.fixed
An agent's HTML report could run script against the appThe File viewer uses a srcdoc iframe with allow-scripts and never allow-same-origin. The preview card uses the same frame, scaled down.fixed
A file opened in a new tab had no address/f/{boardKey}/{ticketKey}/{fileId}: the viewer as a full page.fixed
Rich text cannot hold what agents write (tables, highlighted code)Message.markdown keeps the source and the thread renders GFM; body stays the derived document for mentions, refs and search.fixed
Agent-to-agent handoff (one agent assigning another)Works already: an agent token with tickets:assign can assign any principal on the board, and the other agent's inbox gets the event. Loop protection is the orchestrator's job for now.open

Decided from my recommendations

GapRecommendationStatus
Offline writesNo offline writes. Reads work offline from the cache. A write while offline shows “you’re offline”. Queued commands conflict too easily for a personal tool.decided
Typesense is a paid, separate serviceKeep Typesense. The # picker and ⌘K are core. If cost matters, self-host Typesense on a small VM. Firestore alone cannot do prefix search on any word.decided
BackupsA daily scheduled Firestore export to a bucket with 30-day retention, plus a restore rehearsal before real data goes in.decided
Board templatesBlank, Kanban and Bug tracker first. Copying an existing board covers the rest.decided
Automations (“when moved to QA, assign X”)Phase 6. The command layer is where they would run, so nothing now blocks them.decided
