BackendDriver

v1

An artifact is a small static website that lives inside TaskManager. This one script is its whole backend: Firestore, the Realtime Database, Storage and a per-viewer key-value store, all fenced to that one artifact and available only to the signed-in people it is shared with.

Copy, paste, publish

One index.html is a complete artifact. Put the tag in the page, use window.BackendDriver, publish the folder. 

<!doctype html>
<meta charset="utf-8" />
<title>Guest book</title>
<form id="f"><input id="text" placeholder="Say something" required /> <button>Post</button></form>
<ul id="list"></ul>

<script src="__ORIGIN__/backend-driver/v1/driver.js"></script>
<script type="module">
  const db = window.BackendDriver;
  await db.ready;                                   // the handshake with TaskManager is done

  // Live: runs now, and again whenever anyone it is shared with posts.
  db.firestore.onList('/entries', { orderBy: ['at', 'desc'], limit: 50 }, (docs) => {
    list.replaceChildren(...docs.map((d) => {
      const li = document.createElement('li');
      li.textContent = `${d.data.by}: ${d.data.text}`;
      return li;
    }));
  });

  f.onsubmit = async (e) => {
    e.preventDefault();
    await db.firestore.add('/entries', { text: text.value, by: db.me.name, at: db.serverTime });
    text.value = '';
  };
  f.hidden = db.me.readOnly;                        // viewers of a read-only artifact cannot write
</script>

// vite.config.ts —  base: './'   (artifacts are served under a prefix: asset paths must be relative)

import db from '__ORIGIN__/backend-driver/v1/driver.mjs';

// Types: __ORIGIN__/backend-driver/v1/driver.d.ts  (one flat file, no imports)
  • v1/driver.js — the script tag; sets window.BackendDriver.
  • v1/driver.mjs — the same thing as an ES module (export default and a named BackendDriver).
  • v1/driver.d.ts — the types.
  • latest/ holds the same three files under a moving name. Pin v1.

The API

db.firestore get(path) → { id, path, exists, data } · set(path, data, { merge? }) · update(path, patch) · delete(path) · add(collection, data) · list(collection, { where, orderBy, limit, startAfter }) · onDoc(path, cb) · onList(collection, query, cb) → unsubscribe()
db.rtdb get · set · update · push · remove · on(path, cb) → unsubscribe()
db.storage upload(path, blob, { contentType? }) · url(path) (short-lived, for <img src>) · list(prefix) · delete(path)
db.kv get(key) · set(key, value) · delete(key) — per viewer. Use it where you would have used localStorage, which an artifact does not have.
db.tickets boards() · list(board, query?) · onList(board, query, cb, onError?) · get('ENG-42') · create(board, ticket) · update(key, patch) · comment(key, markdown) — the tickets of boards the artifact's owner granted it (Settings › Board access), read or read & write. Always as the person looking: they see and change only what their own role on that board allows. Names, not ids; Markdown descriptions; times in milliseconds.
db.me { uid, name, email, photoURL, role, readOnly }
db.artifact { id, name, buildId }
db.serverTime Put it anywhere in a value you write; it becomes the server's timestamp.
db.on(name, cb) 'readonly' (your write access changed) · 'revoked' (you lost access) · 'build' (a newer build was published)
  • Paths are the artifact's own: '/todos/a1' and 'todos/a1' are the same, .. is refused. A Firestore document has an even number of segments, a collection an odd number.
  • Firestore timestamps arrive as Date; a Date you write becomes a timestamp.
  • Errors are rejected Promises with a code: permission-denied, not-found, invalid-argument, quota, unavailable.
  • At most 50 live listeners per open tab; one upload is at most 25 MB.

On your machine: the mock

Open the artifact outside TaskManager (vite dev, a file from disk) and the driver says so in the console and becomes a mock backend: the same API over a store kept in this browser's localStorage. db.mock is true, so you can show a banner.

?role=viewer Be an owner (the default), editor or viewer.
?readonly=1 The artifact is read-only for viewers (and makes you a viewer if no role is given).
?mock=1 Force the mock, e.g. inside a preview pane that frames your page.
Publishing, sharing and everything else — creating an artifact, publishing a build from the SDK, REST or MCP, tokens and scopes — is at /integrate (one file for an LLM: /llms-full.txt). In the app, an artifact's Settings › Builds takes a zip or a folder.
