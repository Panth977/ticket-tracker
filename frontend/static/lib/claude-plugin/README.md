# TaskManager — Claude Code plugin

Version 1.4.0 · updated 2026-10-05 · generated by `scripts/gen-integration.mjs` from the running API.
The guide this came from: https://taskmanager-example.web.app/integrate/claude

Four things in one folder:

- **an MCP server** — `taskmanager` at `https://taskmanager-example.web.app/mcp`, the whole API as tools;
- **a skill** — `skills/taskmanager/SKILL.md`, so Claude knows what a board, a ticket, a thread and a task list
  are, and what the rules are, without being briefed. It carries `llms-full.txt` verbatim as a reference file,
  which is the entire generated API reference, offline;
- **a second skill** — `skills/artifact/SKILL.md`, for building *artifacts*: small websites kept inside
  TaskManager with their own data — and for reading and writing that data from outside the page. It ships a
  complete single-file example and a Vite template;
- **five slash commands** — the daily loop: `/tm-inbox`, `/tm-triage`, `/tm-new`, `/tm-ticket`, `/tm-standup`.

## 1 · Get a token

https://taskmanager-example.web.app/account/tokens → **New token** → **Account token**. It acts as you across every board you are on, and loses a
board when you do. Preset **Full account**, or tick fewer boxes — a scope only ever narrows what you can already
do. The string is shown once.

```bash
export TM_TOKEN='tm_live_…'     # put this in ~/.zshrc or ~/.bashrc
```

(To have Claude act as one of your **agents** instead — its own name on every change — use that agent's
token: one per agent, generated on its page at https://taskmanager-example.web.app/agents. It has no board and no checkboxes; the
agent's role on each board is what it may do.)

The plugin reads `TM_TOKEN` from the environment of the shell that starts Claude Code. It deliberately contains
no credential of its own.

## 2 · Install

**From the marketplace command** — this folder is its own marketplace:

```text
/plugin marketplace add ./claude-plugin
/plugin install taskmanager@taskmanager
```

Use the path you unzipped to (an absolute path works anywhere). `/plugin` lists what is installed;
`/plugin uninstall taskmanager@taskmanager` removes it.

**Or from a local folder**, with no marketplace registered:

```bash
claude --plugin-dir ./claude-plugin
```

## 3 · Check it

```text
/mcp        taskmanager → connected, and its tools listed
/help       the five tm- commands are there
```

Then ask for something small — "list my TaskManager boards". That calls `list_boards` and proves the token, not
just the connection. If the commands appear but every call fails with 401, `TM_TOKEN` was not exported in the
shell that started Claude.


## Staying current

This bundle is generated with the API it describes. `https://taskmanager-example.web.app/integrate.json` carries the live `version` and
`contentSha256`; when they differ from the ones above, download https://taskmanager-example.web.app/lib/claude-plugin.zip again.

## Without the plugin

The same server, no bundle:

```bash
claude mcp add --transport http taskmanager https://taskmanager-example.web.app/mcp \
  --scope user --header "Authorization: Bearer $TM_TOKEN"
```

You lose the skill and the commands, and keep the tools.
